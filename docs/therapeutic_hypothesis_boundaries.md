# Therapeutic Hypothesis Boundaries

The therapeutic view may describe disease-level mechanisms, target classes, modality categories, documented public examples, risks, unknowns, assay types, trial links, and validation experiments.

It must not diagnose a person, predict personal disease risk, recommend a medication or dose, provide a prescription, claim efficacy for the user, call a personalized drug ready, provide synthesis instructions, or encourage self-experimentation. Every therapeutic object carries `notForPersonalTreatment: true` and the interface repeats that boundary.

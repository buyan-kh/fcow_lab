# Public Data Sources

Future adapters may target ClinVar, gnomAD, Open Targets, Ensembl, NCBI Gene, PubMed, Europe PMC, PharmGKB, and ClinicalTrials.gov. DrugBank is conditional on licensing permission.

This phase deliberately uses deterministic local fixtures instead of uncontrolled requests. Each fixture has a source title, stable fixture identifier, URL-shaped provenance link, retrieval date, excerpt, evidence state, and limitations. An adapter may be added only after the local data contract and privacy threat model are reviewed.
